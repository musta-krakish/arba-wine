# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это за репозиторий

Это не программный проект: здесь нет кода, сборки, линтеров и тестов. Репозиторий — рабочая папка исследования для дипломного проекта по специальности «Электроснабжение сельского хозяйства»: проектирование системы электроснабжения винодельческого завода в Казахстане (в первую очередь Алматинская область).

Полное техническое задание — [Claude_Code_Winery_Electrical_Research.md](Claude_Code_Winery_Electrical_Research.md). Перед началом работы прочитай его целиком; ниже только ключевые правила.

## Объём исследования

- Приоритетные предприятия: АО «Голд Продукт» / Turgen Wines, Arba Wine, винодельческий завод ISSYK, затем другие заводы Алматинской области, при нехватке данных — другие регионы Казахстана.
- Только винодельческое производство и его электрические нагрузки. Виноградники, орошение, БПЛА, переработку отходов и т. п. не исследовать, если они не являются нагрузкой завода.
- Юридический адрес компании и адрес производственного объекта — разные вещи, не смешивать.

## Структура результатов

Все результаты кладутся в папку `Winery_Electrical_Research/` в корне репозитория:

1. `01_Предприятия.md` — заводы, реквизиты (БИН), адреса площадок, мощности, контакты
2. `02_Генпланы.md` — найденные планы и схемы со ссылками на первоисточник
3. `03_Электроприемники.xlsx` — электроприёмники по цехам (если Excel недоступен — CSV с теми же данными)
4. `04_Электроснабжение.md` — источник питания, ТП, трансформаторы, напряжения, категории надёжности, нагрузки
5. `05_Нормативы.md` — нормативные документы РК: обозначение, название, область применения, статус действия
6. `06_Сравнение_предприятий.md` — сравнительная таблица и выбор трёх лучших объектов с позиции проектировщика электроснабжения
7. `07_Недостающие_данные.md` — что запросить, зачем, у кого, чем заменить, плюс готовый запрос главному энергетику/инженеру
8. `08_Источники.md` — полный реестр источников с проверенными ссылками

В конце работы — краткое инженерное заключение: какой завод лучше всего подходит для диплома, какие данные уже есть, что нужно запросить.

## Правила достоверности (главный приоритет)

Каждому техническому показателю присваивается ровно один статус:

- **ПОДТВЕРЖДЕНО** — есть достоверный источник именно по этому предприятию
- **ТИПОВОЕ** — из документации производителя оборудования или аналогичного предприятия
- **РАСЧЁТНОЕ** — получено инженерным расчётом, формула указана
- **НЕИЗВЕСТНО** — достоверных данных нет

Оборудование в таблице электроприёмников разделяется на группы: **А** — подтверждено для конкретного предприятия; **Б** — типовое для заводов сопоставимой мощности; **В** — предложено только для учебного проектирования.

Обязательные запреты:

- Не выдумывать генпланы, однолинейные схемы, трансформаторы, мощности, контакты, характеристики оборудования.
- Не выдавать условную схему за реальный генплан; если генплана нет — так и написать и перечислить исходные данные для его разработки.
- Не приписывать предприятию оборудование без документального подтверждения.
- Рекламные описания не использовать как инженерные исходные данные.
- Для каждого существенного утверждения — ссылка, название источника, дата публикации, страница (если применимо); доступность ссылок проверять.
- Если веб-поиск или доступ к источникам недоступен — сообщить об этом, а не имитировать исследование.

## Порядок работы

Сначала проверить, что веб-поиск и создание файлов работают. Затем: найти и проверить предприятия → собрать публичные технические данные → оборудование и его характеристики → электроснабжение → сравнительная таблица → выбор завода → итоговые файлы и заключение.

Язык всех результатов — русский. Приоритет — достоверность и техническая пригодность данных, а не объём текста.
