# 08. Реестр источников

Дата итоговой проверки ссылок: **01.11.2026**. Реестр включает все ссылки из файлов `01`–`07` и из `03_Электроприемники.xlsx`: 209 записей, из них 207 со ссылкой и 2 без ссылки (снимки Esri, СП 52.13330.2016). Ссылки adilet.zan.kz в разделе 6 даны дополнительно к рабочим копиям и в счёт не входят.

## Итог проверки доступности

Открыта — 183; Таймаут zakon.uchet.kz — 14; Закрыта для робота или отдаёт заглушку — 7; 404 — 2; Таймаут — 1.

Что это значит:

- **Открыта** — сервер вернул страницу или файл (HTTP 200/206), заголовок страницы проверен на «мягкую» 404.
- **Таймаут zakon.uchet.kz** — сайт рабочих копий НПА не отвечал при итоговой проверке. При подготовке `05` в тот же день он открывался. Для каждого акта рядом дана официальная ссылка на **adilet.zan.kz**. Сам adilet отвечает, но текст и статус акта подгружает через API с авторизацией, поэтому автоматически их не проверить. **Перед защитой открыть каждый акт на adilet.zan.kz в браузере.**
- **Закрыта для робота (403 / 468) или отдаёт заглушку** — сайт отказывает автоматическим запросам (2ГИС вместо карточки отдаёт заглушку). Это не значит, что ссылка мертва: часть этих страниц открывалась при сборе 31.10.2026. Проверить в браузере.
- **Не открывается (404)** — две ссылки: лифлет Vigo/Enoveneta PL (строка 03 Б № 59, цифра и раньше была только из сниппета) и страница Energoprojekt Visokogradnja (цифры с неё и в `02` помечены как неподтверждённые). На выводы проекта они не влияют.

## Как проверялось

1. Все ссылки извлечены скриптом из файлов `01`–`07` и всех листов `03`.
2. Запрос `curl` с заголовком браузера, переходами по редиректам и ограничением 2 КБ (коды 200/206). При ошибке — повтор без проверки сертификата, затем повтор с таймаутом 60 с.
3. Для HTML-страниц с кодом 200 проверен `<title>` на признаки «мягкой» 404 («не найдено», «404», «error»). Таких не найдено.
4. Ключевые страницы — сайты предприятий, сетевых компаний, карточки prg.kz — сверены по заголовку: он совпадает с названием источника.

Скрипты: `scripts/08/check_urls.sh`, `scripts/08/build_registry.py`.
